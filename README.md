# 🔐 Week 3 – Password Security & Recovery | NetworkWalks

## 📌 Overview

As part of my **Week 3 cybersecurity training at NetworkWalks**, I explored password security and recovery techniques using **John the Ripper** and a PDF password recovery tool available through the NetworkWalks website.

This task helped me gain practical exposure to password auditing, password recovery concepts, and the importance of protecting sensitive information.

## 🎯 Objectives

* Understand basic password security concepts.
* Explore password auditing using John the Ripper.
* Practice password recovery in an authorized learning environment.
* Learn about PDF password protection and recovery.
* Understand the importance of strong passwords.

## 🛠️ Tools Used

| Tool                 | Purpose                                    |
| -------------------- | ------------------------------------------ |
| John the Ripper      | Password auditing and recovery experiments |
| NetworkWalks Website | PDF password recovery practice             |
| Linux Terminal       | Executing commands and managing files      |

## 🔍 Tasks Completed

### 1. Password Auditing with John the Ripper

* Explored John the Ripper and its role in password security testing.
* Practiced password recovery using an authorized test file.
* Learned how password strength affects resistance to guessing attacks.
* Observed the importance of secure password storage.

### 2. PDF Password Recovery

* Explored the PDF password recovery feature available through the NetworkWalks website.
* Practiced with a PDF file that I was authorized to access.
* Learned how PDF password protection can help restrict access to documents.
* Reviewed the importance of protecting confidential files.

## 📚 Key Learnings

* Password auditing helps identify weak passwords.
* Strong, unique passwords improve account security.
* Password recovery depends on factors such as password complexity and the protection method used.
* Sensitive documents should be protected using appropriate security controls.
* Password testing should only be performed on files and systems for which permission has been granted.
